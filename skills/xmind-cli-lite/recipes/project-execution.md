# Recipe: 项目执行图

适用：目标拆解、里程碑、任务分派、风险跟踪。

## 骨架

默认 `mindmap`；时间推进用 `timeline`，但一页不要塞太多阶段。

## 草稿

```markdown
# 项目 X

## 目标

- 成功标准
- 不做的事

## 工作流

### 需求

- [ ] 访谈
- [ ] 范围确认

### 实现

- [ ] 核心路径
- [ ] 异常路径

### 上线

- [ ] 灰度
- [ ] 回滚演练

## 风险

- 依赖延期
- 数据迁移

## 待定

- 预算
- 人力
```

## 补充状态与浮动主题

```json
[
  {"op":"label","topic":{"path":["工作流","需求","访谈"]},"add":["this-week"]},
  {"op":"marker","topic":{"path":["风险"]},"add":["flag-red"]},
  {"op":"floating","title":"Parking lot","position":{"x":420,"y":60}},
  {"op":"add","parent":{"path":["Parking lot"]},"title":"待决策：预算"}
]
```

## 约束

- 状态用 label/marker，不要每次改标题。
- 任务标题以动词开头；验收标准放备注。
- 里程碑不超过 5 个；超过就拆项目。
- 不在图里写完整计划文档；图负责结构和优先级。
