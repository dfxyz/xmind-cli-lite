# Markdown 输入语法

只用于 `create`，不是往返格式。

## 支持

```markdown
# 根主题

## 分支

### 子分支

- 列表项也是主题，可嵌套
  - 二级列表
    - 三级列表

1. 有序列表同样是普通主题
2. 不自动编号

> 备注第一行
> 备注第二行，支持 **粗体**、*斜体*、`代码`、[链接](https://example.com)

- [ ] 未完成
- [x] 已完成

![本地图](images/x.png)

[单独成行的链接](https://example.com)
```

## 规则

- 全文恰好一个 H1；否则报错。用 `--title` 可以省略 H1 或覆盖 H1。
- H2-H6 按层级嵌套；跳级时挂到最近的上级标题（H2 后直接 H4，H4 是 H2 的子级）。
- 列表层级按缩进；列表项和标题可以混用。
- `>` 连续行成为最近前置主题的备注；空行结束备注块。多条备注会合并。
- `- [ ]` / `- [x]` 去掉勾选符，加 label `todo` / `done`。
- 行内粗体/斜体/代码/链接只影响备注的 `realHTML`；主题标题始终是纯文本。
- 整行只有一个 `[标题](url)`：新建一个子主题，标题为链接文字，`href` 为 url。
- 整行只有一个 `![alt](path)`：图片挂到最近前置主题；alt 忽略。
- 相对图片/链接按 Markdown 文件所在目录解析；stdin 按当前目录解析。
- 本地链接转绝对 `file:///` URI 并百分号编码。
- 评论、引用之外的普通段落一律报错并给行号，避免静默丢内容。

## 独立成行的陷阱

Markdown 会把相邻行合并成一个段落。下面这样写，图片和链接会被当成同一段而报错：

```markdown
![图](a.png)
[链接](https://example.com)
```

正确写法是留空行：

```markdown
![图](a.png)

[链接](https://example.com)
```

## 不支持（会报错并给行号）

- 表格、代码块、水平线、HTML 块、front-matter。
- 标题/备注/列表项文本中的图片。
- 普通段落（除非整行是链接或图片）。
- 嵌套备注、备注中的列表/标题。
- SVG、URL、网络路径图片。

## 图片

- PNG / JPEG / GIF / WebP。
- 复制进 `resources/<sha256>.<ext>`，manifest 自动登记。
- 默认宽度 320，但不放大：原图更窄时用原宽。

## 链接

- 主题的 `href` 是整题链接，标题内不能有局部链接。
- `https://`、`mailto:` 等带 scheme 的原样保留。
- 本地路径带空格或中文时可用 `%20` 写法，工具会解码后再编码。
